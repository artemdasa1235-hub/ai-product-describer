# AI Product Describer — генератор описаний товаров по фото

Приложение на Python + Streamlit, которое принимает **фото товара** и через LLM API
генерирует готовое продающее описание для карточек на маркетплейсах.

## Что умеет

- Загрузка фото товара (jpg/png)
- Автоматическое определение категории, характеристик и преимуществ товара по изображению
- Генерация продающего описания с структурой: заголовок → выгоды → характеристики → призыв к действию
- Настройка тона текста (продающий / нейтральный / короткий для карточки)
- Копирование результата в один клик

## Стек

- Python 3.10+
- Streamlit (интерфейс)
- OpenAI-совместимый API (GPT-4o / GigaChat / DeepSeek — меняется одной строкой в конфиге)

## Быстрый старт

```bash
pip install -r requirements.txt

# укажи свой API-ключ
export OPENAI_API_KEY="sk-..."

streamlit run app.py
```

## Как это работает

1. Пользователь загружает фото товара
2. Мультимодальная модель анализирует изображение и извлекает: категорию, материал, цвет, ключевые особенности
3. Извлечённые данные подставляются в структурированный промпт-шаблон
4. Модель генерирует описание по шаблону маркетплейсов
5. Текст проходит пост-обработку: удаление воды, проверка длины, чистая разметка
